SousaFX version 0.11.6 is out!

Check out the documentation here: [https://rnbo.sousastep.quest/v0.11.6/](https://sousastep.github.io/SousaFX-rnbo-docs/v0.11.6/)

Last year at this time I was sorta freaking out about getting everything ready in time for the fests. The raspberry pi rig wasn't quite working yet, so I had to use my laptop instead, which was a pain. Porting from mac to rpi ended up taking three times as long as I though it would. (due to Hofstadter's law, I guess) Now, the rig works as intended, and walking around with it is gonna be a good time :)

v0.11.6 Release Notes:

- Add octaver.

- Add tremolo to solo FX.

- Add dotted 16th subdivision.

- Add phase rotator to correct tuba's asymmetric waveform.

- Modify binding logic to improve ergonomics.

- Modify parameter tapers to improve musicality.

- Add external FX IO for 7 stereo FX chains, with latency compensation.
